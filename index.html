    Model

    Touch-Aware AI for TouchAI.

    TouchAI is not a chatbot with a theme. It is Touch-Aware AI — built so contact itself is a first-class signal: how hard, how fast, where, and what that means next.

    • AwareLive contact updates force, motion, and zone.
    • RememberEach contact writes to touch memory.
    • AnswerLanguage stays grounded in what was felt.

    API

    Run Touch-Aware AI.

    import { createTouchAI } from './src/touchai.js'

const ai = createTouchAI() // Touch-Aware AI

ai.sense('start', { x, y, nx, ny, pressure })
ai.sense('move',  { x, y, nx, ny, pressure })
const aware = ai.sense('end')
// aware.headline · aware.detail · aware.force · aware.zone

ai.ask('What did you last feel?')
