The gap

Models can think. They can’t touch.

Chat and generation are read-only. When a model needs to act in the real world, it needs hands — a safe action layer between tokens and systems.

For AI models

Plug TouchAI into your model.

Export tools in the shape your provider expects. When the model returns tool calls, TouchAI executes them and returns results for the next turn.

SDK

      
One runtime. Every model.

      
npm install ./sdk

import { createTouch, createWebAdapter, forModel } from 'touchai-sdk'

const touch = createTouch({
  allow: ['web.click', 'web.type', 'web.read', 'http.request'],
  adapters: { web: createWebAdapter('#world') },
})

const model = forModel(touch, 'openai')
// model.tools  → pass to chat.completions
// model.system → system prompt (hands, not brain)

// Model returned tool_calls?
const handled = await model.handle(completion)
// handled.results → feed back as tool messages
