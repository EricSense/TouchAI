Touch is a language. TouchAI is fluent.

Most models only see text and pixels. TouchAI is built to understand contact — how hard, how fast, where, against what — and to speak the meaning inside the motion.

  • Sense Pointer and touch streams become contact samples: place, pressure, path, time.
  • Understand Gestures, materials, force, and intent are interpreted together — not as raw coordinates.
  • Speak TouchAI answers in language grounded in what it actually felt.

API

Put touch understanding in your product.

import { createTouchAI } from './src/touchai.js'

const ai = createTouchAI()

ai.sense('start', { x, y, nx, ny, pressure })
ai.sense('move',  { x, y, nx, ny, pressure })
const felt = ai.sense('end')
// felt.text → what TouchAI understood

ai.ask('What material was that?')
